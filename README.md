# Scalable Web-Aware RAG Engine

This project implements a **scalable, web-aware Retrieval-Augmented Generation (RAG) engine**. It features an asynchronous ingestion pipeline using **Redis**, a **FastAPI** backend for queuing jobs and serving queries, and a background worker to process web content.

The system allows users to submit URLs for ingestion. The content is then fetched, cleaned, chunked, embedded, and stored in a **vector database (FAISS)** and a **metadata store (SQLite)**. Users can then query the ingested knowledge base to receive grounded, fact-based answers generated by an **LLM (Google's Gemini)**.

---

## Architecture & Design

The system is decoupled into three main components:

### 1. API (FastAPI)

* User-facing service exposing ingestion and query endpoints.
* Offloads heavy tasks for responsiveness.

### 2. Queue (Redis)

* Message broker between API and Worker.
* Ensures API availability even when workers are busy.

### 3. Worker (Python Process)

* Consumes jobs from Redis queue.
* Handles fetching, cleaning, embedding, and storing data.

---

## Ingestion Workflow

1. User sends a POST `/ingest-url` request with a URL.
2. FastAPI validates and checks job status.
3. Creates a job entry in SQLite with `pending` status.
4. Pushes `job_id` to Redis queue.
5. Returns **202 Accepted**.
6. Worker polls Redis, fetches job.
7. Updates job to `processing`.
8. Fetches and cleans the URL content.
9. Generates embeddings via Sentence Transformers.
10. Stores vectors in FAISS and metadata in SQLite.
11. Marks job as `completed`.

---

## Query Workflow

1. User sends POST `/query` with a question.
2. FastAPI embeds query text.
3. Searches FAISS for similar chunks.
4. Retrieves text + metadata from SQLite.
5. Formats prompt and sends to Gemini API.
6. Returns grounded answer + sources.

## Technology Stack

| Component           | Technology            | Reason                              |
| ------------------- | --------------------- | ----------------------------------- |
| **Backend API**     | FastAPI               | High-performance async API          |
| **Frontend**        | Streamlit             | Rapid, interactive demo UI          |
| **Message Queue**   | Redis (Upstash)       | Lightweight, fast broker            |
| **Metadata DB**     | SQLite (SQLModel)     | Simple local job & chunk store      |
| **Vector DB**       | FAISS                 | Efficient vector similarity search  |
| **Embedding Model** | Sentence Transformers | High-quality open-source embeddings |
| **LLM**             | Google Gemini         | Generates grounded answers          |

## Database Schema

### SQLite (`metadata.db`)

#### IngestionJob

* `id` (int, PK)
* `url` (string, unique)
* `status` (string: pending/processing/completed/failed)
* `error_message` (nullable)
* `created_at` (datetime)
* `updated_at` (datetime)

#### Chunk

* `id` (int, PK)
* `job_id` (FK → IngestionJob.id)
* `chunk_text` (string)
* `vector_id` (int, index)

### FAISS (`vector_store.index`)

* Stores binary embeddings.
* `vector_id` maps directly to FAISS row index.

## API Documentation

Base URL: `http://127.0.0.1:8000`

### **POST /ingest-url**

Submit a URL for ingestion.

**Request Body:**

```json
{
  "url": "https://example.com/some-article"
}
```

**Success (202):**

```json
{
  "message": "URL accepted for ingestion",
  "job_id": 1
}
```

**Error (400):**

```json
{
  "detail": "This URL is already processing."
}
```

**Example:**

```bash
curl -X POST "http://127.0.0.1:8000/ingest-url" \
     -H "Content-Type: application/json" \
     -d '{"url": "https://en.wikipedia.org/wiki/Retrieval-augmented_generation"}'
```

---

### **POST /query**

Query the knowledge base.

**Request Body:**

```json
{
  "query": "What is retrieval-augmented generation?"
}
```

**Success (200):**

```json
{
  "answer": "Retrieval-augmented generation (RAG) is a technique...",
  "sources": ["https://en.wikipedia.org/wiki/Retrieval-augmented_generation"]
}
```

**Example:**

```bash
curl -X POST "http://127.0.0.1:8000/query" \
     -H "Content-Type: application/json" \
     -d '{"query": "What is RAG?"}'
```

## Setup and Running

### 1. Clone Repository

```bash
git clone <your-repo-url>
cd <your-repo-url>
```

### 2. Create Virtual Environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment

```bash
cp .env.example .env
```

Edit `.env`:

```bash
UPSTASH_REDIS_URL="your-upstash-redis-url"
GEMINI_API_KEY="your-gemini-api-key"
```

### 5. Initialize Database

```bash
python rag_core.py
```

### 6. Run Services

```bash
# Terminal 1
uvicorn api:app --host 0.0.0.0 --port 8000

# Terminal 2
python worker.py

# Terminal 3
streamlit run app.py
```

### 7. Use the App

* Open `http://localhost:8501`
* Ingest a URL → Wait for processing → Ask questions.
